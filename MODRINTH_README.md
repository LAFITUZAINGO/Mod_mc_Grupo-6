# Mullet Pozo

**Mullet Pozo** es un mod de aventura, exploración y combate para **Minecraft Forge 1.20.1** creado por el Grupo 6.

---

## 🌟 Características Principales

- **Estructura y Portal del Pozo:** Acceso mediante un pozo místico con mecánicas de portal personalizadas activado arrojando la Llave Moneda.
- **Dimensión Personalizada:** Viaja a las *Tierras Profundas*, un vacío claustrofóbico con una mega-mazmorra subterránea.
- **Jefes y Entidades:**
  - `Mr. Mullet`: Jefe final colosal de 5 metros de altura con múltiples habilidades (modo frenesí, invocación de camejitos, ataques cuerpo a cuerpo de Wither y barra de jefe personalizada).
  - `Profesor Mullet`: Entidad pacífica rescatable con diálogos interactivos y agradecimientos tras superar la aventura.
- **Proyectiles Únicos de Cartas (`CardProjectileEntity`):** Ataques mágicos con trayectoria recta, tarjetas amarillas ralentizantes y tarjetas rojas explosivas con fuego y efecto Wither.
- **Mecánicas de Mazmorra:**
  - Sistema de protección anti-grief (modo aventura: solo se pueden romper bloques colocados por el jugador).
  - Barreras mágicas entre salas que se disuelven al limpiar a los enemigos.
  - Efecto de **Luminiscencia** (`GLOWING`) que resalta a los últimos 3 monstruos de cada sala a través de las paredes.
  - Progresión de acceso mediante Tarjetas Amarillas y Tarjeta Roja.

---

## 📋 Requisitos y Compatibilidad

- **Cargador de Mods (Loader):** Forge (versión `47.4.28` o superior para 1.20.1)
- **Versión de Minecraft:** `1.20.1`
- **Java:** Java 17 o superior
- **Lado:** Cliente y Servidor (Client & Server)

---

## 🚀 Instalación

1. Asegúrate de tener instalado Minecraft Forge para la versión 1.20.1.
2. Descarga el archivo `.jar` de la versión correspondiente (`mullet-1.0.0.jar`).
3. Coloca el archivo `.jar` dentro de la carpeta `.minecraft/mods`.
4. ¡Inicia el juego y disfruta de la aventura!
