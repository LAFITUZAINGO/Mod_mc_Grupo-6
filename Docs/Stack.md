# Stack Tecnológico

#### IAs de apoyo
| IA | Utilización |
| :--- | ---: |
| Gemini | Tareas simples y búsqueda de información |
| Chatgpt | Correción de los documentos Markdown y diferentes diagramas |
| Claude | Lógica y diagramado |
| Antigravity | Vibecoding y testeo |

#### Lenguajes de código
| Lenguajes| Utilización |
| :--- | ---: |
| Java | Para la estructura y lógica de negocio del código |
| MySQL | Estructurar y manejar la base de datos relacional |

#### Gestor de Dependencias y Build
| Herramienta | Utilización |
| :--- | ---: |
| Maven | Gestión automatizada de librerías, dependencias y empaquetado del proyecto |

#### Librerías y Conectores
| Librerías | Utilización |
| :--- | ---: |
| JDBC (mysql-connector-j) | Middleware para conectar y ejecutar consultas en MySQL |
| jBCrypt | Hashing y verificación segura de contraseñas de usuarios |
| JFreeChart | Generación y renderizado de gráficos estadísticos de evolución |
| Dotenv (dotenv-java) | Carga de variables de entorno para no exponer credenciales sensibles de la base de datos |

#### Interfaz Gráfica (UI)
| Tecnología | Utilización |
| :--- | ---: |
| JavaFX / Swing | Construcción y diseño de las vistas e interfaces de usuario para la aplicación de escritorio |

#### Infraestructura y Despliegue
| Plataforma | Utilización |
| :--- | ---: |
| Railway | Hosting en la nube para el servidor de base de datos MySQL en entorno de producción |
| Localhost | Servidor de base de datos local para entorno de desarrollo y pruebas |
