# Mullet Pozo

**Mullet Pozo** es un mod de aventura y combate para Minecraft Forge 1.20.1 creado por el Grupo 6.

---

## 🌟 Características Principales

- **Dimensión del Pozo:** Acceso mediante un pozo místico con mecánicas de portal personalizadas.
- **Jefes y Entidades Personalizadas:**
  - `Mr. Mullet`: Jefe con múltiples fases de combate, ataques y habilidades especiales.
  - `Profesor Mullet`: Nueva entidad con mecánicas interactivas y ataques con proyectiles de cartas.
- **Proyectiles únicos:** Ataques de cartas (`CardProjectileEntity`).
- **Mecánicas y Dungeons:** Estructuras subterráneas de desafío.

---

## 📋 Requisitos y Compatibilidad

- **Cargador de Mods (Loader):** Forge (versión `47.4.28` o superior para 1.20.1)
- **Versión de Minecraft:** `1.20.1`
- **Java:** Java 17 o superior
- **Lado:** Cliente y Servidor (Client & Server)

---

## 🚀 Instalación

1. Asegúrate de tener instalado Minecraft Forge para la versión 1.20.1.
2. Descarga el archivo `.jar` de la versión correspondiente (`mullet-1.0.0.jar`).
3. Coloca el archivo `.jar` dentro de la carpeta `.minecraft/mods`.
4. ¡Inicia el juego y disfruta!
